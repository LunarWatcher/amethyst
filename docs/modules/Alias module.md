# Alias module

```zsh
source "$AMETHYST_LOCATION/modules/aliases.zsh"
```

The alias module consists of a small number of functionally default aliases, like making `ls --color` the default for the `ls` command.

The aliases only extend builtin commands, i.e. system defaults. For the aliases currently in use, [see the `aliases.zsh` file](https://codeberg.org/LunarWatcher/amethyst/src/branch/master/modules/aliases.zsh).
